AUBRION RELAY — сервер-посредник для удалённого управления машиной
===================================================================

Это крошечный сервер (один файл server.js, без зависимостей) + веб-панель.
Магнитола подключается к нему, панель шлёт команды.

ЗАПУСК (нужен Node.js 18+):
    RELAY_SECRET=мой_секретный_ключ  PORT=8080  node server.js

После запуска:
  - Веб-панель:  http://АДРЕС_СЕРВЕРА:8080/
  - В панели (⚙ настройки) впиши ID машины и тот же секретный ключ.
  - В приложении на магнитоле впиши адрес сервера, тот же ключ и ID машины.

ПЕРЕМЕННЫЕ:
  RELAY_SECRET  — секретный ключ (одинаковый на сервере, в панели и в приложении).
  PORT          — порт (по умолчанию 8080).

ВАРИАНТЫ ХОСТИНГА:
  1) Свой VPS (любой, ~300-500 руб/мес):
       - установи Node.js:   apt update && apt install -y nodejs npm
       - скопируй папку, запусти:   RELAY_SECRET=... node server.js
       - чтобы работал постоянно:    npm i -g pm2 && pm2 start server.js --name aubrion
       - желательно HTTPS (через nginx + сертификат) — подскажу отдельно.
  2) Бесплатный хостинг (Render.com / Railway.app):
       - загрузи эти файлы, стартовая команда: node server.js
       - переменная окружения RELAY_SECRET=... ; порт берётся из PORT автоматически.
       - получишь готовый адрес вида https://aubrion-xxx.onrender.com

БЕЗОПАСНОСТЬ: ключ — это пароль. Не публикуй его. Для продакшена нужен HTTPS.
